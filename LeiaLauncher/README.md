# Ок Лея

Android-приложение, которое держит микрофон в foreground service, распознаёт фразу «Ок, Лея» и открывает официальное приложение ChatGPT (`com.openai.chatgpt`).

## Использование
1. Установить APK.
2. Разрешить микрофон и уведомления.
3. Нажать «Разрешить поверх других приложений» и включить разрешение.
4. Вернуться в приложение и нажать «Запустить Лею».
5. Сказать: «Ок, Лея».

На Android 14+ после перезагрузки телефона прослушивание нужно запустить вручную снова.
