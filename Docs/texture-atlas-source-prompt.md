# Ballistic Sniper 3.2 material atlas

The production texture atlas was generated as a single exact 4×4 grid for the Unity mobile range.

Final prompt: photorealistic seamless game textures under neutral PBR-style diffuse lighting, with sixteen hard-aligned equal cells ordered as dirt, grass, sandstone, granite; planks, splintered wood, rusted red steel, scratched gunmetal; corrugated steel, terracotta, watermelon skin, watermelon flesh; cracked glass, paper target, snow, concrete. No gutters, labels, logos, watermark, perspective, cross-cell shadows, or merged materials.
